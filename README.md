# Игра Президент

Перед установкой советуется:
  1. Вставить/открыть код в IDLE и в режиме Edit выбрать REPLACE.
  2. Вставить в первую строку player
  3. Вставить во вторую строку Player
  4. Нажать Replace All


------------------------------------------------------------------
# Windows
Перед запуском:
  1. Нажмите Win+R
  2. Введите cmd
  3. В командную строку вставьте текст:
       py -m pip install -U colorama


# Linux / macOS / WSL
Перед запуском:
  1. Откройте терминал
  2. Введите команду:
       python3 -m pip install -U colorama


Это нужно для работы строки:
    from colorama import Fore, Style, init as colorama_init
