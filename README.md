Перед установкой советуется:
  1. Вставить/открыть код в IDLE и в режиме Edit выбрать REPLACE.
  2. Вставить в первую строку player
  3. Вставить во вторую строку Player
  4. Нажать Replace All

# 💻 Windows
Перед запуском:
  1. Нажмите Win+R
  2. Введите cmd
  3. В командную строку вставьте текст:
       py -m pip install -U colorama

# 🐧 Linux / macOS / WSL
Перед запуском:
  1. Откройте терминал
  2. Введите команду:
       python3 -m pip install -U colorama

Это нужно для работы строки:
    from colorama import Fore, Style, init as colorama_init

# 📜 Описание игры

=== Президент: Текстовая стратегическая игра ===

Президент — текстовая стратегическая игра, в которой вы становитесь главой государства.  
Возглавьте страну, управляйте экономикой, обеспечьте благополучие граждан и защитите государство от внутренних и внешних угроз.

───────────────────────────────────────────────────────────────

## 🏭 Управление экономикой
Развивайте промышленность, стройте фабрики и заводы, контролируйте бюджет.

## 🏥 Социальное развитие
Стройте больницы, улучшайте инфраструктуру и повышайте уровень счастья граждан.

## ⚖️ Борьба с коррупцией
Выбирайте: вести честную политику или использовать коррупционные схемы.

## 🪖 Контроль военной мощи
Создавайте военные базы, укрепляйте армию и защищайте свою страну от врагов.

## 🕵️ Тайные операции и разведка
Ведите шпионаж, выявляйте внутренние угрозы и проводите спецоперации.

## 👥 Влияние на население
Поддерживайте социальную стабильность, предотвращайте протесты и мятежи.

## ☢️ Борьба с апокалипсисом
Снижайте угрозу глобального краха, реагируйте на катастрофы и кризисы.

───────────────────────────────────────────────────────────────

# 💡 Подсказки перед стартом

* Управляй экономикой с умом — не вкладывай все ресурсы в одну область.  
* Держи армию в боеготовности — внешние угрозы могут появиться неожиданно.  
* Следи за уровнем счастья — недовольные граждане могут устроить бунт.  
* Контролируй коррупцию — чем выше её уровень, тем больше проблем в стране.  
* Реагируй на кризисы оперативно — природные катастрофы могут обрушить экономику.  
* Не забывай о больницах — без них люди начинают погибать, снижая численность и счастье населения.  
* Строй больницы и загсы — без больницы загс не может функционировать.
